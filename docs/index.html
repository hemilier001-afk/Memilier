Hemilier 桌面智能体

对话 + 工具调用 + 文件/命令操作 + 联网搜索的桌面 AI 智能体，由本地 Ollama 或云端 DeepSeek / OpenAI 兼容模型驱动。

⬇ 下载 Windows 版 所有版本 操作手册 源码 (GitHub)

免安装 · 解压双击运行 · 你的 API Key 仅加密保存在本机，不上传任何第三方

能做什么

💬

智能对话

流式输出，Markdown / 代码高亮 / 数学公式，多轮会话与历史。

🛠️

工具调用

自主读写文件、执行命令、搜索代码，完成多步骤任务。

🌐

联网搜索

内置免密钥联网搜索与网页读取，获取最新资料。

🧠

多模型

本地 Ollama + 云端 DeepSeek / OpenAI / MiniMax，对话内随时切换。

🛒

插件市场

一键安装 Word / Excel / PPT / PDF / 数据 / 图片 技能包。

🔌

MCP 扩展

接入 MCP 服务器（stdio / http / sse），扩展任意外部能力。

🔐

安全沙箱

文件/命令限定在工作区目录；写操作与危险命令需授权确认。

🗂️

工作台

文件树 / 可编辑预览 / Diff / 计划 / 记忆 / Git / 终端。

三步上手

  1. 到 Releases 下载 Hemilier-0.1.0-win.zip，右键全部解压。
  2. 双击 Hemilier.exe 运行（首次 SmartScreen 选「更多信息 → 仍要运行」）。
  3. 打开「设置 → 模型」填入你自己的 API Key（推荐 deepseek-chat），即可开始。
