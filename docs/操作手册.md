## 1. 它能做什么

- **多轮对话**：流式输出，Markdown / 代码高亮 / **数学公式（KaTeX）**，代码块与整条回复一键复制。
- **智能体**：模型可自主调用工具——读写文件、执行命令、搜索代码、**联网搜索 / 读网页**、调用 MCP 工具——完成多步骤任务。
- **多模型**：本地 Ollama，或云端 OpenAI 兼容端点（DeepSeek / MiniMax / OpenAI 等），对话内随时切换。
- **工作区沙箱**：每个对话绑定一个文件夹，所有文件/命令操作都限定在该文件夹内。
- **插件市场**：一键安装 Word / Excel / PPT / PDF / 数据分析 / 图片 等技能包。
- **三个独立空间**、**项目分组**、**自定义指令**、**定时例程**、**应用内文件编辑器 / Diff / 终端 / Git / 记忆面板**。

## 2. 安装与启动

### 2.1 Windows（打包版，推荐普通用户）

1. 拿到安装包 **`Hemilier-0.1.0-win.zip`**，拷到 Windows 电脑。
2. **右键 → 全部解压** 到任意文件夹（如桌面新建一个 `Hemilier` 文件夹）。
   > 注意：必须先解压再运行，不要在 zip 预览里直接双击。
3. 进入解压后的文件夹，双击 **`Hemilier.exe`** 启动。
4. 首次运行若弹出蓝色 **SmartScreen**（因为程序未做数字签名）：点 **“更多信息” → “仍要运行”**。

**适用范围**：64 位 Windows（Intel / AMD）。这是免安装的便携版，解压即用；想换位置直接移动整个文件夹即可。卸载只需删除该文件夹（用户数据另存，见 [§19](#19-数据存储位置与隐私)）。

> 若桌面图标显示成默认图标，是 Windows 图标缓存所致——换个新文件夹解压，或在任务管理器里重启「Windows 资源管理器」即可。

### 2.2 macOS

- **打包版**：双击 `Hemilier.app`，或从 `.dmg` 把它拖进“应用程序”。首次被拦截时右键 →“打开”一次。
- **开发版（源码运行）**：
  ```bash
  npm install
  npm run dev
  ```

### 2.3 运行前提（模型）

程序本身能直接打开，但要真正对话，需要二选一：
- **本地模型**：安装并启动 Ollama（`ollama serve`），并拉取一个支持工具调用的模型（如 `ollama pull qwen2.5`）。
- **云端模型**：在设置里配置 DeepSeek / OpenAI 等 API（见 [§3.2](#32-云端模型deepseek--minimax--openai-等)）。**推荐 `deepseek-chat`**——工具调用最稳。

## 3. 首次使用：配置模型

按 **⌘/Ctrl + ,** 或点左下角 **⚙ 设置** 打开设置面板，切到 **模型 / Models**。

### 3.1 本地模型（Ollama）

1. 确认 **Ollama 地址** 为 `http://localhost:11434`（默认）。
2. 先在终端运行 `ollama serve`，并 `ollama pull qwen2.5`（或 llama3.1 等支持 tool calling 的模型）。
3. 回到设置，**默认模型** 下拉里选中该模型。

### 3.2 云端模型（DeepSeek / MiniMax / OpenAI 等）

在设置的 **模型** 分类里：

1. 点预设按钮快速添加：**+ DeepSeek** / **+ MiniMax** / **+ OpenAI** / **+ 自定义**。
2. 在卡片里填：
   - **Base URL**（预设已填好，如 DeepSeek `https://api.deepseek.com/v1`）
   - **API Key**（你自己的密钥；每个提供方都要填它自己的）
   - **模型名**（逗号分隔，如 `deepseek-chat,deepseek-reasoner`）
3. 这些模型会出现在对话顶部的**模型下拉**里（按提供方分组），选中即用，无需开本地 Ollama。

> 参考 Base URL：DeepSeek `https://api.deepseek.com/v1`；OpenAI `https://api.openai.com/v1`；MiniMax `https://api.minimaxi.com/v1`（具体模型名以你账号控制台为准）。
> **API Key 经系统钥匙串加密保存在本机**，请求由程序主进程直连厂商，不经第三方（见 [§19](#19-数据存储位置与隐私)）。
> **要让智能体真正"动手"（执行命令、联网、改文件），请用支持工具调用的模型**：`deepseek-chat`、`gpt-4o` 最稳；`deepseek-reasoner` 与 MiniMax 系不支持/不擅长工具调用，只适合纯聊天。

界面分三栏（暖珊瑚品牌色 + 冷中性底色，支持深浅主题）：

│            │                      │                │
│ ✎ 新对话    │  消息流 + 工具卡片     │ Files          │
│ 🔍 搜索     │                      │ Preview(可编辑) │
│ 💬 Chats    │                      │ Diff           │
│ 🤝 Cowork   │  ┌────────────────┐  │ Plan           │
│ 💻 Code     │  │ 输入框          │  │ Memory         │
│ ✨ Customize│  │ [+][模式][🎤] 发送│  │ Git            │
│ ⏰ Routines │  └────────────────┘  │ Terminal       │
│ 🔄 Tasks    │                      │                │
│ 📁 Projects │                      │                │

- **左侧栏**：顶部 `☰` 可折叠成窄图标栏（或菜单/`⌘\` 开关）；底部 ⚙ 设置旁显示**当前对话所用模型**。

- **右侧工作区**：可用顶部 `✕` 关闭，或对话头部 `▥` 开关。

## 5. 三个工作空间：Chat / Cowork / Code

左侧导航的 **Chats / Cowork / Code** 是三个**互相独立**的空间：

- 各自维护**自己的对话列表**和**当前对话**，互不干扰、互不串台。
- 在某个空间里**新建对话**，该对话就只属于这个空间。
- **Chat**：纯对话；**Cowork / Code**：切入时自动展开右侧工作区面板（偏文件协作 / 编码）。
- 快捷键 **⌘/Ctrl + 1 / 2 / 3** 在三个空间间切换。

## 6. 对话操作

- **发送**：默认 **Enter 发送**、**Shift+Enter 换行**；可在 设置 → 通用 → **发送方式** 改成 **⌘/Ctrl + 回车 发送**（则 Enter 换行）。
- **流式渲染**：生成时实时渲染 Markdown / 公式，末尾有闪烁光标；点 **停止**（或按 `Esc`）可中断。
- **自动滚动**：输出时若你在底部会**自动跟随**到最新；**向上滚动即停止跟随**、安心看历史，右下角出现 **“↓ 回到底部”** 按钮；**发送新消息会自动回到底部**。
- **代码块复制 / 复制整条回复**：悬停出现“复制”按钮，点了即复制到系统剪贴板。
- **重新生成**：最后一条 AI 回复下方点“重新生成”。
- **编辑并重发**：悬停**你发的消息**点“编辑”→ 回到输入框 → 改完 **重发**（从该消息处截断重跑）。
- **导出对话**：对话头部 **⬇**（或 **⌘/Ctrl + Shift + E**），导出为 Markdown。
- **会话重命名**：左栏对话**双击**标题或点 **✎**。
- **用量提示**：头部 **`~Xk tokens`** 粗估；过长变**琥珀色 ⚠**，较早消息会被自动裁剪以免超出上下文。

## 7. 输入框工具栏（模式 / 附加 / 语音）

### 7.1 ⚡ 运行模式（按对话记忆）

| 模式 | 行为 |
|---|---|
| **⚡ 自动** | 放开全部工具 + MCP，自主读写文件、执行命令、联网 |
| **📋 计划** | 只给只读工具（读文件/列目录/搜索/制定计划），**不修改文件、不执行命令** |
| **💬 对话** | 完全不调用工具，纯聊天 |

> 想让它执行命令 / 联网查资料，**必须在 ⚡ 自动 模式**。

### 7.2 `+` 附加菜单

- **🖼 上传图片**、**📄 上传本地文件**（读入文本上限 100k）、**📁 选择工作区文件夹**、**🧩 管理插件 / MCP**。

### 7.3 `@` 文件引用

输入框打 **`@`** 弹出工作区文件下拉（实时过滤），选中插入 `@相对路径`，智能体据此读取该文件。

### 7.4 🎤 语音输入（ASR）

- 录音在本机进行，音频交主进程发往 **ASR 接口** 转写成文字。
- **需先配置**：设置 → **语音** → 选支持音频转写的提供方（最稳 **OpenAI**），模型填 `whisper-1`。
- 未配置时点 🎤 会直接打开设置。状态：🎤 空闲 → 🔴 录音 → ⏳ 转写 → ⚠️ 出错。

### 7.5 图片 / 视觉输入

- **`+` → 🖼 上传图片**，或在输入框**直接粘贴**剪贴板图片；上方显示缩略图，可移除；可只发图。
- 需**视觉模型**才能看懂：OpenAI `gpt-4o`/`gpt-4o-mini`；Ollama `llava`/`qwen2.5-vl` 等。

## 9. 右侧工作区面板

右栏顶部 7 个标签：

- **Files**：工作区文件树（懒加载，点文件打开预览）。
- **Preview（可编辑）**：默认预览（Markdown/高亮）；点 **编辑** 改内容，**保存** 写回（沙箱内）。过大被截断的文件不可编辑。
- **Diff**：本次会话里智能体每次写/改文件的**前后逐行差异**（绿增红删 + 统计）。
- **Plan**：智能体维护的**任务清单**（○待办 / ◐进行中 / ●完成）。
- **Memory**：**项目记忆**条目（事实/偏好/决策/坑/待办），可增删，详见 [§16](#16-记忆memory)。
- **Git**：分支、暂存/更改列表、暂存/取消暂存、查看 unified diff、填提交信息提交；非仓库可一键 **初始化**（需系统已装 `git`）。
- **Terminal**：在当前工作区敲命令、流式看输出，可停止/清空。

> Diff = "本会话内智能体改了什么"（临时）；Git = "仓库真实版本状态"（持久）。

## 12. Routines 例程 与 Tasks 后台任务

### 12.1 Routines（定时例程）

左栏 **⏰ Routines** → **+ 新建例程**：填 名称 + 指令 + 每隔 N 分钟 + 模型(可选) + 启用。到点自动新建对话运行智能体，完成后弹**系统通知**；也可 **▶运行** 立即跑。

> ⚠️ **后台运行自动放行所有工具调用**（含写文件/执行命令），**请只用于你信任的指令**。
> 若工作区是 **git 仓库**，后台例程会自动在**隔离的 worktree + 独立分支**（`hemilier/<名>-<id>`）里跑，改动提交到该分支、**不碰你当前工作树**；非 git 仓库则原地运行。

### 12.2 Tasks（后台任务）

左栏 **🔄 Tasks**（运行中显示角标）：列出每次后台运行的 运行中/已完成/失败 与时间；点任务跳到其生成的对话。

## 13. 工具与权限（安全）

**内置工具（15 个）**：`read_file`、`write_file`、`edit_file`、`list_dir`、`glob`、`grep`、`run_command`、`fetch_url`（读网页）、`web_search`（**联网搜索，免密钥**）、`load_skill`、`update_plan`、`add_memory`、`forget_memory`、`recall`、`save_skill`。

**权限网关**：

- 只读工具（读文件 / 列目录 / 搜索）默认**自动放行**（可在设置关闭）。
- **写文件 / 执行命令 / 联网 / 调用 MCP 工具** → 弹**授权框**（显示要改的 diff / 要跑的命令 / 要访问的 URL / 搜索词），你点“允许 / 拒绝”后才执行。
- 授权框可勾 **“本会话内记住此类操作”**，本次运行内同类不再追问（重启复位）。
- **危险命令**（如 `rm -rf`、`sudo`、`format C:`、`curl … | sh`、`git reset --hard` 等）**强制二次确认**，即使勾了“记住”也照样弹框。

**工作区沙箱**：文件 / 命令操作都限定在当前对话的**工作区目录**内，越界（含 `..`、符号链接）一律拒绝。
**联网安全**：`fetch_url` 会拦截 localhost/内网/云元数据地址，并逐跳复检重定向。

## 14. 接入 MCP 服务器

在 **设置 → MCP** 文本框里写 JSON，每个键是一个 server，可多个。支持 **stdio（本地启动进程）** 与 **http / sse（远程）** 两类：

```json
{
  "filesystem": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\你\\Desktop"]
  },
  "github": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-github"],
    "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx" }
  },
  "remote": {
    "url": "https://example.com/mcp",
    "type": "http"
  }
}
```

- 字段：`command`（stdio）或 `url`（远程，配 `type: "http"` 或 `"sse"`）；`args`、`env`、`enabled: false`（临时停用）。
- 启用的 server 工具以 `mcp__<server>__<工具>` 暴露给模型，调用经权限确认。
- 点 **「测试连接」** 可逐个探活（显示工具数或错误原因）。
- **改命令/参数/URL 会自动重连**，无需重启；连接报错/调用失败会丢弃死连接以便下次重连。
- stdio 方式前提是对应命令可运行（`npx` 需 Node）。

## 15. 技能（Skills）与插件市场（Plugins）

### 15.1 插件市场（一键安装）

设置 → **技能与插件** → **🛒 插件市场**：内置一批技能包，点 **安装** 即用、点 **卸载** 移除。包含：

| 插件 | 能力 |
|---|---|
| 📝 Word（.docx） | 读/写/改文档、标题、表格 |
| 📊 Excel（.xlsx） | 读写单元格、公式、多 sheet |
| 📑 PowerPoint（.pptx） | 生成幻灯片、标题页、要点 |
| 📕 PDF | 提取文本/表格、生成 PDF |
| 🧮 数据分析 | pandas 清洗/统计/透视 |
| 🖼️ 图片处理 | 缩放/裁剪/转格式/水印 |

> 办公文档类技能靠智能体调用 Python 库实现，**需本机有 Python 环境**（技能内已含 `pip install …` 引导，缺库时智能体会自动安装）。

### 15.2 自定义技能 / 插件

- **Skills**：把 `SKILL.md`（或含 `SKILL.md` 的文件夹）放进全局 skills 目录或工作区 `.hemilier/skills/`，即被自动识别；智能体用 `load_skill` 按需加载。
- **Plugins**：设置里点 **「从文件夹…」** 选一个含 `plugin.json` 的文件夹安装（可声明 mcpServers 与 skills 子目录），或点 **「打开插件目录」** 手动放入。可启停/卸载。
- 智能体也能用 `save_skill` 把稳定流程**自动沉淀**成技能复用。

## 16. 记忆（Memory）

Hemilier 有跨对话的长期记忆：

- **项目记忆**：存在工作区 `.hemilier/memory.json`，注入系统提示。右栏 **Memory** 标签可查看/增删条目（类型：事实 / 偏好 / 决策 / 坑 / 待办）。智能体也会在发现长期有用的信息时用 `add_memory` 自动记一条。
- **历史召回**：智能体用 `recall` 检索你过去所有对话（你说“上次/之前我们讨论过…”时它会去翻）。
- **反思沉淀**：点对话头部 **🧠** 让它回顾本次对话，自动 `add_memory` / `save_skill`。

## 19. 数据存储位置与隐私

对话、设置、项目、例程、图片都存在本机用户数据目录：

- **Windows**：`%APPDATA%\Hemilier\`（按 `Win + R` 输入 `%APPDATA%` 进入）
- **macOS**：`~/Library/Application Support/Hemilier/`

其中：`settings.json`（设置）、`conversations.json`（对话）、`projects.json`（项目）、`routines.json`（例程）、`images/`（上传的图片）、`window-state.json`（窗口大小/位置）、`main.log`（运行日志）。

**隐私与安全**：
- **API Key 用系统钥匙串（Windows DPAPI / macOS Keychain）加密**后写入 `settings.json`（带 `safe:` 前缀的密文），不是明文。
- **打包文件不含任何密钥**——发给别人的 zip 里没有你的 API Key；对方需在自己机器的设置里填自己的密钥。
- 加密的密钥**绑定当前系统账户**，换电脑需重新填一次。
- 卸载程序不会自动删这些数据；彻底清除可手动删该文件夹（JSON 若损坏，程序会自动备份为 `.corrupt-*.bak` 再以空配置启动，不会静默丢数据）。

## 20. 常见问题与排错

**Q：发送后提示“尚未选择模型”。**
A：去设置选默认模型；本地模型要先 `ollama serve` 并 `ollama pull`，云端模型要配好 API Key。

**Q：模型只在对话里"说"命令，却不真正执行 / 查不了天气。**
A：① 确认在 **⚡ 自动模式**；② **换工具调用强的模型**（`deepseek-chat` / `gpt-4o`）——**MiniMax、deepseek-reasoner 不会调用工具**，只能聊天，这不是程序问题；③ 用最新版 `Hemilier.exe`。

**Q：切到 DeepSeek 用不了。**
A：DeepSeek 要填**它自己的** API Key（MiniMax 的不能用）；模型选 **`deepseek-chat`**（`deepseek-reasoner` 不支持工具，`deepseek-v4-flash` 不是有效模型名）；在旧对话里切换后报错的话，**新建一个对话**再试。

**Q：Windows 双击 exe 被 SmartScreen 拦。**
A：程序未签名，点“更多信息 → 仍要运行”。

**Q：本地 Ollama 连不上。**
A：确认 `ollama serve` 已运行、地址 `http://localhost:11434`；模型需支持工具调用（qwen2.5 / llama3.1 等）。

**Q：复制按钮没反应。**
A：已修复为系统原生剪贴板；若用的是旧打包版，请更新到最新 `Hemilier.exe`。

**Q：语音点了没反应 / 转写失败。**
A：先在设置配置 ASR（提供方 + 模型）；允许麦克风权限；DeepSeek 无音频转写，语音请用 OpenAI 等。

**Q：MCP 工具没出现。**
A：检查 JSON 格式与命令可用性，点「测试连接」看报错；首次 `npx -y` 会联网下载包，稍慢。

**Q：办公插件（Word/Excel/PPT）不工作。**
A：这类技能需本机装了 **Python**；缺库时智能体会尝试 `pip install`，请允许其执行命令。

**Q：例程没按时触发。**
A：确认例程为“启用”、程序保持运行（关闭则不触发）；调度按固定分钟间隔检查。
